# 会员系统部署指南

## 安装步骤

### 1. 编译项目

会员系统已集成到 AzerothCore 的 Custom 脚本模块中，编译时会自动包含。

```bash
# 进入构建目录
cd /path/to/azerothcore/build

# 重新配置 (如果已配置过)
cmake .. -DCMAKE_INSTALL_PREFIX=$HOME/azeroth-server -DCMAKE_BUILD_TYPE=RelWithDebInfo \
  -DSCRIPTS=static -DMODULES=static

# 编译
make -j$(nproc)

# 安装
make install
```

### 2. 执行数据库迁移

运行以下 SQL 脚本来创建会员系统所需的数据库表：

```bash
# 连接到 acore_world 数据库
mysql -u root -p acore_world < /path/to/azerothcore/data/sql/base/db_world/vip_member.sql
mysql -u root -p acore_world < /path/to/azerothcore/data/sql/base/db_world/vip_skill_access.sql
```

或者直接登录 MySQL 手动执行：

```sql
-- 创建会员信息表
source /path/to/azerothcore/data/sql/base/db_world/vip_member.sql;

-- 创建技能权限表
source /path/to/azerothcore/data/sql/base/db_world/vip_skill_access.sql;
```

### 3. 部署配置文件

将配置文件模板复制到配置目录：

```bash
cp /path/to/azerothcore/etc/vip.conf.dist /path/to/azerothcore/etc/vip.conf
```

根据服务器需求编辑 `vip.conf` 文件，调整会员权益参数。

### 4. 启动服务器

启动或重启 worldserver，会员系统会在启动时自动加载：

```bash
# 启动 worldserver
cd /path/to/azeroth-server
./bin/worldserver
```

启动后检查日志，确认会员系统加载成功：

```
Loading member data from database...
Loaded X member records
Member system configuration loaded successfully
```

## 配置说明

### vip.conf 配置文件

```conf
# 是否启用会员系统 (1=启用，0=禁用)
MemberSystem.Enable = 1

# 各等级掉落率加成 (0.2 = 20%, 1.0 = 100%)
MemberSystem.DropRateBonus.0 = 0       # VIP0
MemberSystem.DropRateBonus.1 = 0.2     # VIP1
MemberSystem.DropRateBonus.2 = 0.5     # VIP2
MemberSystem.DropRateBonus.3 = 1.0     # VIP3

# 各等级天赋点数加成 (每 10 级奖励点数)
MemberSystem.TalentPointBonus.0 = 0    # VIP0
MemberSystem.TalentPointBonus.1 = 1    # VIP1
MemberSystem.TalentPointBonus.2 = 2    # VIP2
MemberSystem.TalentPointBonus.3 = 5    # VIP3
```

### 会员等级说明

| 等级 | 名称 | 掉落率加成 | 天赋点加成 (每 10 级) | 技能权限 |
|------|------|-----------|-------------------|---------|
| VIP0 | 普通会员 | 0% | 0 点 | 普通技能 |
| VIP1 | 高级会员 | 20% | 1 点 | VIP1 及以下 |
| VIP2 | 超级会员 | 50% | 2 点 | VIP2 及以下 |
| VIP3 | 至尊会员 | 100% | 5 点 | 所有技能 |

## 数据库表说明

### vip_member 表

存储玩家会员信息。

| 字段 | 类型 | 说明 |
|------|------|------|
| account_id | int | 账号 ID (主键) |
| tier | tinyint | 会员等级 (0-3) |
| expire_time | int | 过期时间 (Unix 时间戳，0 表示永久) |
| create_time | bigint | 创建时间 |
| update_time | bigint | 更新时间 |

### vip_skill_access 表

配置技能学习所需的最低会员等级。

| 字段 | 类型 | 说明 |
|------|------|------|
| spell_id | int | 技能 ID (主键) |
| min_tier | tinyint | 最低会员等级要求 (0-3) |

#### 配置示例

```sql
-- 设置技能 ID 12345 需要 VIP1 才能学习
INSERT INTO `vip_skill_access` (`spell_id`, `min_tier`) VALUES (12345, 1);

-- 设置技能 ID 67890 需要 VIP3 (至尊会员) 才能学习
INSERT INTO `vip_skill_access` (`spell_id`, `min_tier`) VALUES (67890, 3);
```

## GM 命令使用

### 设置会员等级

```
.vip set [玩家名] [等级]
```

- 玩家名：在线或离线玩家的角色名
- 等级：0-3 (0=VIP0, 1=VIP1, 2=VIP2, 3=VIP3)

示例：
```
.vip set PlayerName 3          # 设置玩家为至尊会员
.vip set PlayerName 0          # 降级为普通会员
```

### 查询会员信息

```
.vip info [玩家名]
```

显示玩家的会员等级、掉落率加成、天赋点加成等信息。

示例：
```
.vip info PlayerName
```

输出：
```
=== VIP Info for PlayerName ===
VIP Level: 3
Drop Rate Bonus: 100.0%
Talent Point Bonus: 5 per 10 levels
```

### 重载配置

```
.vip reload
```

重新加载技能权限配置（从数据库）。

示例：
```
.vip reload
```

输出：
```
Member system configuration reloaded.
```

## 常见问题

### Q1: 会员系统没有生效？

**检查步骤：**

1. 确认 `vip.conf` 文件中 `MemberSystem.Enable = 1`
2. 检查服务器日志是否有会员系统加载信息
3. 确认数据库表 `vip_member` 已正确创建
4. 使用 `.vip info` 命令检查玩家会员等级

### Q2: 如何设置永久的会员？

将 `expire_time` 设置为 0 或 NULL 即可：

```sql
UPDATE `vip_member` SET `expire_time` = 0 WHERE `account_id` = 123;
```

### Q3: 如何批量设置会员？

```sql
-- 将所有账号设置为 VIP1
INSERT INTO `vip_member` (`account_id`, `tier`, `expire_time`, `create_time`, `update_time`)
SELECT `id`, 1, 0, UNIX_TIMESTAMP(), UNIX_TIMESTAMP() 
FROM `account` 
ON DUPLICATE KEY UPDATE `tier` = 1, `update_time` = UNIX_TIMESTAMP();
```

### Q4: 天赋点数加成如何计算？

天赋点数加成按每 10 级计算：

- VIP1: 每 10 级 +1 点 (10 级 +1 点，20 级 +2 点，30 级 +3 点...)
- VIP2: 每 10 级 +2 点 (10 级 +2 点，20 级 +4 点，30 级 +6 点...)
- VIP3: 每 10 级 +5 点 (10 级 +5 点，20 级 +10 点，30 级 +15 点...)

### Q5: 掉落率加成如何实现？

掉落率加成通过增加额外掉落数量实现：

- 20% 加成 = 20% 概率额外掉落 1 个物品
- 50% 加成 = 50% 概率额外掉落 1 个物品
- 100% 加成 = 100% 概率额外掉落 1 个物品（相当于双倍掉落）

### Q6: 如何禁用会员系统？

临时禁用（不删除数据）：

```conf
# 在 vip.conf 中设置
MemberSystem.Enable = 0
```

然后重启服务器或执行 `.vip reload`。

### Q7: 如何彻底移除会员系统？

1. 删除数据库表：
```sql
DROP TABLE IF EXISTS `vip_member`;
DROP TABLE IF EXISTS `vip_skill_access`;
```

2. 删除配置文件：
```bash
rm /path/to/azerothcore/etc/vip.conf
```

3. 重新编译（移除会员系统代码）
